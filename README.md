# Document Knowledge API

An AI technical documentation portfolio project demonstrating the evolution of a developer-facing REST API into an AI-powered knowledge platform.

The project brings together **API documentation, API testing, AI API integration, RAG, agentic AI, AI automation, and Python-based API workflows** into one connected technical documentation project.

## Project Overview

The **Document Knowledge API** is designed as a progressive technical documentation project.

Each stage builds on the previous stage to demonstrate how modern AI-enabled applications can combine APIs, retrieval systems, AI models, agents, automation, and scripting.

### Project Evolution

**REST API + JSON**  
↓  
**Postman + OpenAPI**  
↓  
**AI API Integration**  
↓  
**RAG**  
↓  
**Agentic AI**

**Python**
